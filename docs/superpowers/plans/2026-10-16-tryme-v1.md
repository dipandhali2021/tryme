# TryMe v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local Next.js website — live virtual clothes try-on (Decart Lucy VTON, 20s per try) with a live-scraped Amazon/Flipkart/Myntra clothes panel.

**Architecture:** Next.js App Router app. Left half: camera + Decart realtime session driven by a pure state machine (20s clock starts on first AI frame, restarts per garment). Right half: store panel backed by `/api/search` (per-store scraper adapters parsing embedded JSON, disk-cached) and `/api/proxy-image` (image proxy + cache). Short-lived Decart tokens minted server-side by `/api/realtime-token`.

**Tech Stack:** Next.js (App Router, TS), Tailwind v4, Cojeev UI (shadcn registry), `@decartai/sdk`, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-16-tryme-design.md`

## Global Constraints

- Model: `models.realtime("lucy-vton-latest")`; connect with `speed: "fast"`; video-only getUserMedia at the model's `fps`/`width`/`height`.
- `DECART_API_KEY` lives only in `.env.local` (server). Never sent to the browser. Tokens: `client.tokens.create({ expiresIn: 300, allowedModels: ["lucy-vton-3.6"], allowedOrigins: [req origin] })`.
- **20s per try**; clock starts on first AI frame; picking another garment restarts the clock; warn at ≤5s; auto-disconnect at 0.
- Garment images reach Decart via `client.files.upload(blob)` → file id (not URLs; Decart can't fetch `localhost`).
- Layout: studio = 50/50 left camera / right store panel. Landing → `/studio`. Name: **TryMe**. Dark default + light toggle (`data-mode`, persisted to localStorage).
- Aesthetic: Cojeev components + motion presets (Glide), sleek minimal. Store-product cards keep INR prices and link to the real product page.
- Scrapers: Flipkart parse `window.__INITIAL_STATE__`; Myntra parse `window.__myx`; Amazon is blocked server-side → tab shows "Open Amazon search" + drag/paste fallback. Search cache TTL 6h, negative 2min; images cached by sha1. Politeness: sequential requests, browser-ish UA, cache-first.
- No auth, payments, deployment, or analytics in v1. Desktop-first.
- Every task ends with `npm test` green, `npm run build` green, and one conventional commit.

## Review Focus

- Camera/mic denied or absent → clear state, retry path, no crash.
- Token/connect failure or mid-session drop → clean end + toast, retry gets a fresh 20s.
- Scraper drift / Amazon block / store error → per-store error state + fallback; cached results still serve; app never crashes.
- Image CDN blocking our proxy → 302 to the original URL so cards still render.
- Fast garment switching while live, and expiry mid-request → deterministic: no double-connect, no orphaned countdown, single recording.

### Task 8: Session state machine (pure)

**Files:**
- Create: `src/lib/session/machine.ts`, `src/test/machine.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export const LIVE_SECONDS = 20; export const WARN_AT = 5;
  export type Phase = "camera_off" | "camera_ready" | "connecting" | "warming" | "live" | "ending" | "recap" | "error";
  export type SessionEvent =
    | { type: "CAMERA_ON" } | { type: "CAMERA_OFF" } | { type: "CAMERA_FAILED"; message: string }
    | { type: "GARMENT_SELECTED"; imageUrl: string }
    | { type: "CONNECTED" } | { type: "FIRST_FRAME" }
    | { type: "TICK" } | { type: "DISCONNECTED" }
    | { type: "ERROR"; message: string } | { type: "RETRY" } | { type: "RECAP_DISMISSED" };
  export type SessionState = { phase: Phase; remaining: number; warn: boolean; garmentUrl: string | null; error: string | null; recapReady: boolean };
  export function initialSessionState(): SessionState;
  export function reduce(state: SessionState, event: SessionEvent): SessionState;
  ```
- Rules: `GARMENT_SELECTED` from `camera_ready` → `connecting`; `FIRST_FRAME` → `live`, `remaining = 20`; `TICK` decrements, sets `warn` at ≤5, `EXPIRED`-effect handled by hook when `remaining` hits 0 → treat as `ending` (reduce does NOT auto-move; hook dispatches `DISCONNECTED` after closing → `recap`, `recapReady: true`). `GARMENT_SELECTED` while `live`/`warming` → `remaining = 20` again. `ERROR` → `error` phase + message. `RETRY` → `connecting` if `garmentUrl` set else `camera_ready`. `CAMERA_OFF` → `camera_off` (clears recap/error).
